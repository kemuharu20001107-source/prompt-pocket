# Prompt Pocket Ver.1 利用ガイド

Prompt Pocket は、ページ構成を考え、画像生成用のプロンプトを作り、完成までの進捗を管理する作業台です。画像の生成は PixAI などで手動で行います。アプリは生成サービスへのログインや自動入力を行いません。

## 最初の作品を作る

1. 下部ナビの「作品」を開き、「＋ 作品を作る」を押します。
2. 作品名、任意のキャラクタープリセット、最初のページ数を入力します。ページ数は 0〜100 で指定できます。
3. 「作品を作成」を押します。構成をまとめて貼り付けたい場合は 0 ページから始めてください。
4. 作品画面の「作品設定・共通プロンプト」でキャラクター名、作品メモ、共通プロンプト、共通ネガティブを設定します。

作品一覧には「27 / 40 ページ完成」「67%」などの進捗、作成日、更新日が表示されます。「完成」になったページだけが完成数に含まれます。「採用」は最終確認などが残っているページとして扱います。

入力の変更は自動保存されます。画面上部の「保存済み」を確認してください。保存失敗が表示された場合は「保存を再試行」を押せます。保存ボタンを毎回押す必要はありません。

## ページをまとめて登録する

作品画面の「＋ ページを追加・一括登録」を開きます。タイトルを入力して 1 ページ追加するか、「構成メモを一括登録」に次のような内容を貼り付けてください。

```text
1|導入
2|会話
3|振り向く
4|目元アップ
5|全身
```

タイトルだけの改行区切りにも対応します。空行は無視され、現在の末尾から連番で追加されます。入力の番号は並び替え指定ではありません。ページテンプレートを選ぶと、新しい各ページにプロンプト・ネガティブ・メモが入ります。

ページ一覧は状態で絞り込めます。ページごとに状態をワンタップで変更でき、「再生成」だけの一覧も開けます。編集画面ではタイトル、内容 / 構成メモ、ページ固有プロンプト、ネガティブ、シーン、修正メモを設定します。前ページ・次ページやページ選択で移動できます。

「複製」は元ページの後ろに新しいページを挿入し、以後の番号を振り直します。シーン、プロンプト、ネガティブ、メモ、背景・服装・画風、辞書選択などを引き継ぎます。状態は「未作成」になり、再生成理由と修正メモはクリアされます。直接編集した完成プロンプトも引き継ぐため、必要に応じて「自動生成に戻す」を選んでください。

作品やページの削除には確認が表示されます。削除の取り消し機能はないため、必要な制作データは JSON バックアップに保管してください。

## 共通設定・シーン・範囲設定

完成プロンプトは次の順序で自動合成されます。

```text
作品共通プロンプト
＋ キャラクタープリセット
＋ シーンの背景・服装・時間帯・照明・プロンプト
＋ ページ固有の背景・服装・画風・プロンプト
＋ 辞書から選択したプロンプト
```

ネガティブプロンプトは、作品共通、キャラクター、シーン、ページ固有の内容を合成します。キャラクター名の表示だけでは生成用の設定になりません。キャラクタープリセットのプロンプトを登録して作品へひもづけてください。

作品画面の「シーン設定」で、同じ背景・衣装・時間帯・ライティングなどを登録します。「範囲一括設定」で P8〜P16 のような開始・終了ページを指定し、適用したい項目にチェックを入れて「指定範囲へ適用」を押します。シーン、背景、服装、画風を一度に設定でき、チェックしていない項目は変更されません。チェックした項目を空欄で適用すると、その項目を解除できます。

シーンとキャラクターはページから参照されます。設定を編集すると、使用中ページの自動合成プロンプトに反映されます。範囲設定の背景・服装・画風は、各ページの設定として保存されます。

完成プロンプトと完成ネガティブは直接編集できます。直接編集後はその内容を保持し、共通・シーン・辞書などの変更で置き換えません。空欄への編集も保持します。合成内容へ戻す場合は「自動生成に戻す」または「ネガティブを自動生成に戻す」を押してください。

## 辞書をタップして組み立てる

1. 先に作品のページを開きます。
2. 「辞書」タブ、またはページ内の「辞書からタップで追加」を開きます。
3. プロンプトのボタンをタップして追加します。同じボタンをもう一度タップすると解除されます。選択中はチェックと色で表示されます。
4. 「選択中」の欄で重みを変更できます。0.8、0.9、1.0、1.1、1.2、1.3、1.4、1.5 はワンタップ、0.1〜3.0 は手入力できます。

重みが 1.2 の場合は `(looking at viewer:1.2)` の形式になります。1.0 は通常のプロンプト本文で出力します。

検索は日本語などの表示名、英語などの本文、メモに対応します。カテゴリ、お気に入り、最近使用で絞り込め、使用回数が多い順にも並べられます。追加したときに使用回数と最終使用日時を記録し、解除では使用回数を増やしません。

「＋ プロンプトを登録」で表示名、出力本文、カテゴリ、メモを保存します。各項目の編集やお気に入り登録もできます。「カテゴリを管理」でカテゴリを追加・編集・削除できます。カテゴリを削除した場合、その項目は「その他」へ移ります。

辞書の本文を編集・削除しても、すでにページへ追加した本文は保持されます。ページで古い本文を更新したい場合は、選択を解除してから変更後の辞書項目を追加してください。

## プリセット・キャラクター・テンプレート

「プリセット」タブでは 3 種類を管理できます。

| 種類               | 使い方                                                                                                                                                                            |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 組み合わせ         | 品質、夜の室内などを保存し、「現在のページに追加」でページの末尾へ追加。完成プロンプトを直接編集している場合も、その編集内容へ追加します。                                        |
| キャラクター       | 名前、基本プロンプト、ネガティブ、メモを保存し、作品作成時または「現在の作品で使用」で選択。変更は使用中の作品の自動合成へ反映されます。                                          |
| ページテンプレート | 顔アップ、会話などのプロンプト、ネガティブ、構成メモを保存し、ページ作成時に選択。既存ページへ適用する場合は確認後にその 3 項目を置き換え、完成プロンプトの直接編集を解除します。 |

組み合わせとテンプレートは「現在のページから読み込む」で登録フォームに取り込めます。名前や内容を確認して保存してください。組み合わせ・テンプレートの登録後の編集は、すでに適用したページを書き換えません。

キャラクタープリセットを削除するときは、使用中の作品の名前を残し、そのプロンプトを作品共通設定へ移して保持します。

## 制作モードで順番に進める

「制作」タブから作品を選びます。「未完成を順番に」は「完成」以外のページを番号順で表示します。「再生成だけ」は再生成ページだけを処理します。

1. ページの内容と完成プロンプトを確認します。
2. 「コピー」または「プロンプトをコピー」を押します。ネガティブも別にコピーできます。
3. PixAI などで手動で生成します。
4. Prompt Pocket に戻り、制作状態を選びます。

| 状態           | 用途                                                     |
| -------------- | -------------------------------------------------------- |
| 未作成         | 構成やプロンプトの準備を始めるページ                     |
| プロンプト完成 | 生成用プロンプトの準備ができたページ                     |
| 生成済み       | 画像を生成し、確認待ちのページ                           |
| 再生成         | 修正して生成し直すページ                                 |
| 採用           | 使用する画像を決めたページ                               |
| 完成           | そのページの制作を終えた状態。進捗の完成数に含まれます。 |

自動移動がオンの場合、再生成以外の状態を選ぶと、そのページより後ろの対象ページへ移動します。「再生成」を選んだ場合は同じページに留まり、手・表情・顔・構図・背景・服装・キャラクター崩れ・画質・その他から理由を複数選択できます。必要な修正メモを入力して「理由を記録して次へ」を押します。理由とメモは入力時点で自動保存されます。

「設定」の「状態を変更したら次のページへ進む」をオフにすると、通常の状態変更後も同じページに留まります。「理由を記録して次へ」「このページはあとで」や前後移動では手動で進められます。

末尾まで進むと制作セッションが終了します。生成済み・採用などの未完成ページは、次のセッションでも対象になります。「もう一度確認する」で対象を再確認できます。画面下のコピー・ネガティブ・完成ボタンも利用してください。

コピー時に「コピーしました」が表示されます。ブラウザの制限などでコピーできない場合は、プロンプト欄を長押ししてコピーできます。Prompt Pocket は別の生成サービスへコピー内容を自動送信しません。

## 自動保存とバックアップ

作品、ページ、辞書、プリセット、キャラクター、シーン、お気に入り、使用履歴、設定は IndexedDB に保存されます。同じ端末・ブラウザプロファイル・オリジン（プロトコル、ホスト、ポート）で開くと再利用できます。別端末や別ブラウザには自動同期されません。開発用のポートを変えた場合も保存先が別になります。

### JSON を書き出す

1. 「設定」→「全データを JSON エクスポート」を押します。
2. ダウンロードした `prompt-pocket-日付_時刻.json` を保存します。iPhone では「ファイル」などへ保管してください。
3. 端末・ブラウザ・URL の変更前やブラウザデータの削除前にも書き出します。

JSON には直接編集したプロンプト、重み、再生成理由、使用回数、選択中作品・ページなども含まれます。ブラウザ内だけの自動保存とは別に JSON を保管してください。プライベートブラウズの終了やブラウザデータの削除で保存内容が消えることがあります。

### JSON から完全復元する

1. 必要なら現在のデータを先にエクスポートします。
2. 「JSON から復元」で 20 MB 以下のバックアップファイルを選択します。ファイルを使えない場合は「JSON を貼り付けて復元」へ内容を貼り付け、「JSON の内容を確認」を押します。
3. 復元予定の作品・ページ・辞書・キャラクター・プリセット・テンプレート・シーン数を確認します。ここではまだ保存データを変更しません。
4. 「全データを置き換えて復元」を押します。追加・結合ではなく全データの置き換えです。「復元をキャンセル」も選べます。
5. 「全データを復元しました」が表示された後、作品を開いて確認します。

不正な JSON、未対応のバージョン、重複 ID、不正な参照・状態・重みなどは読み込み時に拒否されます。拒否されたバックアップで現在のデータが上書きされることはありません。

## Ver.1 の範囲と今後

Ver.1 は構成管理、プロンプト作成、制作進捗管理を提供します。外部 API キー、外部サーバー、クラウド同期、登録・課金・SNS は使用しません。大量の元画像・完成画像の保存、PixAI の自動ログイン・入力・生成は実装していません。

将来の採用画像プレビュー用にページへ `previewAssetId` を予約していますが、Ver.1 には画像登録画面や画像本体の保存はありません。Ver.2 の候補は、小さな採用画像プレビュー、PWA のオフライン起動・ホーム画面へのインストール、優先度・保留・セッション再開などの制作キュー改善です。

スマートフォン用 UI は 390px 前後の Chromium で検証します。実機 iPhone Safari はまだ未検証です。起動・ビルド・テストの実行方法は [README](../README.md) を参照してください。
