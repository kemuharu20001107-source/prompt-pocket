## 修正した主な不具合

- 空の辞書選択 ID をバックアップの検証で拒否。
- 復元中の同時入力を抑止し、画面と IndexedDB の置換結果を一致。
- 自動移動オフ時、完成や再生成対象外になったページもその画面に保持。
- 保存失敗でバックアップまで止まらないよう、画面上の最新データを出力。
- プリセットへの読み込みで辞書選択・重み・直接編集を保持。
- ローカル LAN の HTTP でも ID を作れるよう、UUID の代替処理を追加。
- テスト成果物の HTML が開発サーバーの自動再読込を起こさないよう、監視対象から除外。

## 確認範囲

今回確認した範囲で未解決の重大な不具合はありません。実機 iPhone Safari は未検証です。390px の Chromium はスマートフォン用レイアウト・タッチ操作の確認であり、実機のブラウザや OS の動作確認とは異なります。

外部へのデプロイは行っていません。ユーザー登録、API キー、有料サービス、クラウド同期、PixAI 自動操作、大量画像保存も導入していません。
