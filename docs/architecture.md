# Prompt Pocket Ver.1 設計

React + TypeScript + Vite の静的 SPA。外部 API・認証・クラウドサービスは使わない。

- `types.ts`: バージョン付きデータ型。作品にページ・シーンを内包し、キャラクター・辞書・テンプレート・プリセットは共有。
- `model.ts`: プロンプト合成、複製、一括登録、範囲適用、制作キュー、進捗計算を純粋なドメイン処理に分離。
- `storage.ts`: IndexedDB の単一スナップショットをトランザクションで保存。起動時読込、書込直列化、バックアップ検証。
- `store.tsx`: 変更を同期的に状態へ反映し、自動保存を直列で実行。保存失敗を表示し、未保存状態を保護。
- `views/`: 作品一覧・作品詳細、ページ編集/制作、辞書、プリセット、設定。

画面下部に 5 項目の固定ナビ。390px を基準、入力は 16px 以上、操作領域は原則 44px 以上。PC は幅を制限しサイドナビを表示。

プロンプト合成は共通 → キャラクター → シーン → ページ設定 → 辞書選択。直接編集は null と空文字を区別する上書き欄。自動合成に戻す操作で解除。シーン変更は参照ページへ即反映するが直接編集内容は維持。

制作モードは未完成または再生成ページを順番に処理。状態選択後は今のページより後の対象へ移動、末尾でセッション完了。設定から自動移動を解除できる。

バックアップは schemaVersion を含む全データ JSON。構造・ID・参照・値を検証してから IndexedDB へ原子的に置換。不正な JSON は既存データへ影響しない。置換前にバックアップを推奨し明示確認する。

画像は将来の Blob ストアを参照する `previewAssetId` を予約し、Ver.1 は画像本体を保存しない。
