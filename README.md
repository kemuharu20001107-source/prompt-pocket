# Prompt Pocket

公開URL: [https://prompt-pocket-seven.vercel.app](https://prompt-pocket-seven.vercel.app)

スマートフォンで使う画像生成用プロンプト作成・管理ツールです。辞書の語をタップして組み合わせ、完成文を直接編集してコピーできます。

## 使い方

1. 「作成」で日本語・英語検索、カテゴリ、お気に入り、最近使った項目から語を選びます。
2. 選択中の項目を上下ボタンで並べ替えたり、重みを変更できます。
3. 完成プロンプトはそのまま直接編集できます。「コピー」でクリップボードへ保存します。
4. 「辞書」で登録・編集・カテゴリ管理・一括貼り付けができます。
5. 「プリセット」で名前付きの組み合わせを保存・読み込みできます。「履歴」には成功したコピーが最大100件残ります。

## 保存とバックアップ

辞書、カテゴリ、お気に入り、メモ、使用情報、参考画像、プリセット、履歴、設定、作成途中の内容はこのブラウザのLocalStorageに保存します。画像生成API、ユーザー登録、データベースは使いません。

ブラウザの保存データを消した場合や、別の端末・ブラウザ・URLへ移った場合は、自動では引き継がれません。日常利用には同じ固定URLを使ってください。

「設定」の「バックアップを書き出す」でJSONを保存し、「バックアップを読み込む」で復元します。読込前に形式と件数を確認し、置換前データを復旧用に保持します。バックアップはファイル（iPhoneの「ファイル」アプリ等）へ定期的に保存してください。

旧 Prompt Builder Pal の保存キー `prompt-builder-store-v1` は同じオリジンに存在すれば読み込みます。旧環境から別URLへ移る場合は旧JSONの退避・読込が必要です。旧形式のJSONも読み込みに対応します。ブラウザ内の本データはGitHubには保存しません。

新しい保存キー：
- `prompt-pocket-data-v1`：辞書等
- `prompt-pocket-draft-v1`：作成途中
- `prompt-pocket-recovery-v1`：置換前の控え
- `prompt-pocket-corrupt-v1`：破損元の控え

## 開発

実行ファイルは `web/` にあります。外部ライブラリ・ビルド・APIキーは不要です。Node.js 20以降なら：

```sh
npm run dev
npm test
```

開発URLは `http://127.0.0.1:8000` です。Pythonを利用する場合は `python3 -m http.server 8000 --directory web` でも配信できます。`web/index.html` のファイル直接開きはES modulesや保存・コピーの制約があるため、HTTP/HTTPSで配信してください。

公開時は `web/` の内容を配信ルートへ置きます。Vercelの場合はFrameworkなし、Build Commandなし、Install Commandなしで静的ファイルを配信できます。GitHubにあるだけではアプリURLは公開されません。

元のReact/TanStack実装の辞書・編集部品・未完成基盤は `legacy/` に保持しています。実行用ではなく移行・保守の参照です。元Lovableプロジェクトは削除していません。

## スマホでの確認項目

- 390px幅で検索・候補選択・完成欄・下部ナビが重ならない
- 日本語入力中にカーソルや変換が壊れない
- 手動追記・重み・順序変更が次のチップ操作で消えない
- 選択追加・解除、全解除で辞書が消えない
- 辞書・カテゴリ・一括登録、お気に入り、最近使用、頻度順
- プリセット・履歴から保存した完成文を復元
- コピーと通知、再読み込み後の保存
- JSONバックアップの往復、不正JSONで元データが変わらない
- 保存容量不足や保存禁止時に、保存成功を誤表示せず元データを保持

実ブラウザでの動作確認はユーザーが担当する方針です。コードレビューや純粋ロジックの検証と、実画面を操作した確認は区別します。
