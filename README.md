# Prompt Pocket Ver.1

同人誌・漫画の構成、画像生成用プロンプト、制作進捗をまとめる、スマートフォン中心の制作作業台です。390px 前後の画面を基準に、大きな操作ボタンと下部ナビゲーションを用意しています。PC でも使用できます。

作品データはブラウザの IndexedDB に自動保存します。Lovable、有料外部サービス、画像生成 API、外部サーバー、API キー、ユーザー登録は不要です。React などの無償 npm パッケージをローカルで使用します。

## 起動

Node.js 22.12 以上を推奨します。

```bash
cd /workspace/prompt-pocket
npm ci
npm run dev
```

表示された開発用 URL をブラウザで開きます。通常は `http://localhost:5173` です。開発サーバーは `0.0.0.0` で起動します。別の端末から使う場合は、その端末から到達できるホストの URL を開いてください。端末や URL が変わると保存データの場所も変わります。

```bash
npm run build
npm run preview
```

ビルド結果は `dist/` に生成されます。プレビューの通常の URL は `http://localhost:4173` です。アプリにバックエンドはありません。Ver.1 には PWA のオフライン起動機能は含まれません。

## 保存とバックアップ

保存先は、同じ端末・ブラウザプロファイル・オリジン（プロトコル、ホスト、ポート）の IndexedDB です。`localhost:5173` と `localhost:4173`、Safari と別のブラウザ、PC と iPhone はそれぞれ別の保存先です。クラウド同期は行いません。

「設定」→「全データを JSON エクスポート」で作品、ページ、辞書、キャラクター、シーン、プリセット、テンプレート、お気に入り、使用履歴、設定をまとめて保存できます。iPhone ではダウンロードした JSON を「ファイル」などに保管してください。

復元は JSON ファイルの選択または貼り付けに対応します。構造・バージョン・ID・参照・値を検証し、内容の確認後に「全データを置き換えて復元」を押すと既存データを置き換えます。復元前に現在のデータを書き出してください。不正なバックアップは拒否され、現在のデータは保持されます。ブラウザデータの削除やプライベートブラウズの終了に備え、JSON を定期的に保管してください。

## テスト

```bash
npm test
npm run test:e2e
npm run build
```

ドメイン処理と IndexedDB は Vitest + fake-indexeddb、画面操作は Playwright で検証します。E2E テストは開発サーバーを起動し、390px 幅の Chromium で主要操作と保存・復元を確認します。

この Codex Cloud 環境ではシステム Chromium を使用します。`playwright.config.ts` の実行ファイルの既定値は `/usr/bin/chromium` です。別の場所にインストールされている場合は次のように指定してください。

```bash
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

E2E の実行には指定パスの Chromium が必要です。現在の環境では Playwright 用ブラウザのネットワークダウンロードは不要です。390px 幅の Chromium による確認は、実機 iPhone Safari での確認を代替するものではありません。実機 Safari の動作はまだ未検証です。

## 技術構成

React 19 / TypeScript / Vite 7 / Lucide React。静的 SPA で、IndexedDB にバージョン付きの全データスナップショットをトランザクション保存します。

| ファイル                                        | 役割                                                           |
| ----------------------------------------------- | -------------------------------------------------------------- |
| `src/types.ts`                                  | データモデル、制作状態、将来の画像参照 `previewAssetId`        |
| `src/model.ts`                                  | プロンプト合成、複製、一括登録、範囲設定、制作キュー、進捗計算 |
| `src/storage.ts`                                | IndexedDB 読み書き、JSON 書き出し・読み込み、バックアップ検証  |
| `src/store.tsx`                                 | アプリ状態、自動保存の直列処理、保存失敗・通知、データ置換     |
| `src/seed.ts`                                   | 初期辞書・テンプレート・プリセットと任意のサンプル作品         |
| `src/App.tsx`                                   | 画面切り替え、PC・スマートフォンのナビゲーション               |
| `src/views/`                                    | 作品、ページ・制作、辞書、プリセット、設定画面                 |
| `src/components/UI.tsx`                         | 共通 UI と削除確認                                             |
| `src/styles.css`                                | ライトテーマとレスポンシブレイアウト                           |
| `tests/model.test.ts` / `tests/storage.test.ts` | 制作処理と保存・バックアップの単体テスト                       |
| `playwright.config.ts`                          | E2E のブラウザ・画面幅・開発サーバー設定                       |

設計の概要は [設計メモ](docs/architecture.md) に記載しています。

## Ver.1 の対象外と Ver.2 候補

PixAI へのログイン・入力・生成の自動化、外部画像生成 API、クラウド同期、ユーザー登録、課金、SNS、大量の画像保存は実装していません。

Ver.2 では、`previewAssetId` を使った採用画像の小さなプレビュー、PWA のオフライン起動・ホーム画面へのインストール、制作キューの優先度・保留・セッション再開を追加すると、日々の制作をさらに進めやすくなります。
